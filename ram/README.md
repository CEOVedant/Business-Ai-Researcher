# 🔎 ResearchOS

AI-powered business research and competitive intelligence agent.

## 🚀 Overview

ResearchOS is an agentic AI research system designed to investigate business questions, discover sources, extract evidence, identify potential conflicts, and generate an executive research report.

## 🧠 Agent Pipeline

ResearchOS uses multiple stages:

1. Research Planner
2. Source Discovery
3. Source Extraction
4. Evidence Analysis
5. Contradiction Detection
6. Synthesis
7. Executive Report

## ✨ Features

- Business research question analysis
- Web source discovery
- Webpage text extraction
- Evidence extraction
- Potential contradiction detection
- Executive research summary
- Streamlit dashboard
- Optional AI-powered analysis

## 🛠️ Tech Stack

- Python
- Streamlit
- OpenAI API
- BeautifulSoup
- Requests
